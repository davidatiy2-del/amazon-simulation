# אמזוניה — אפליקציית אנדרואיד

התיקייה הזאת היא פרויקט אנדרואיד מלא (Gradle). המשחק עצמו נמצא בתוך האפליקציה, בתיקייה
`app/src/main/assets/www`, ורץ בלי אינטרנט: three.js והגופנים כלולים.

## להתקין את האפליקציה המוכנה
קובץ ה־APK שמגיע יחד עם הפרויקט חתום ומוכן להתקנה:
1. מעבירים את הקובץ לטלפון (בכבל, בדוא״ל או ב־Drive).
2. פותחים אותו בטלפון. אם הטלפון שואל, מאשרים "התקנה ממקורות לא ידועים" לאפליקציה שפתחה את הקובץ.
3. האפליקציה "אמזוניה" מופיעה במסך הבית. גרסה חדשה מותקנת מעל הישנה, והמשחקים השמורים נשארים.

## השמירות
- באפליקציה המשחקים נשמרים בטלפון עצמו, בתוך האפליקציה. גרסה חדשה שמותקנת מעל הישנה משאירה אותם, אבל **מחיקת האפליקציה מוחקת גם אותם**.
- למשחק שפותחים כאן בקלוד יש שמירות נפרדות, והן נשמרות גם בחשבון (ולכן נפתחות בכל מחשב או טלפון).
- להעביר משחק בין האפליקציה, הדפדפן ומכשירים אחרים: בתפריט הראשי "המשחקים שלי", הכפתור 📤 ליד המשחק, "להעתיק".
  בצד השני: "המשחקים שלי", "📥 לטעון משחק מקוד", ומדביקים. הקוד הוא גם גיבוי טוב: אפשר לשמור אותו בפתק.

## משחקים שמגיעים עם האפליקציה
קודי העברה שנמצאים בתיקייה `assets/gifts` בפרויקט הראשי (קבצים עם סיומת `.amz`) נכנסים לאפליקציה,
והיא מוסיפה אותם לרשימה "המשחקים שלי" בפעם הראשונה שהיא נפתחת. כך מגיעה העיר "שבט הלוחמים".
משחק כזה שנמחק לא חוזר.

## לבנות מחדש בעצמך
צריך Android SDK (פלטפורמה 36 ו־build-tools) ו־JDK 17 ומעלה.

```
cd android
./gradlew assembleRelease
```

ה־APK נוצר ב־`app/build/outputs/apk/release/app-release.apk`.

## החתימה
- מפתח החתימה: `keystore/amazonia.jks`, והסיסמאות בקובץ `keystore.properties`.
- **שומרים את שני הקבצים האלה.** כל גרסה חדשה של האפליקציה חייבת להיחתם באותו מפתח, אחרת הטלפון לא יתקין אותה מעל הגרסה הקודמת.
- לפני העלאה לחנות (Google Play) כדאי ליצור מפתח חדש ופרטי, ולא לשתף אותו.

## לעדכן את המשחק בתוך האפליקציה
המשחק נבנה מהחלקים שבתיקייה `src` של הפרויקט הראשי: `python3 build.py` מעתיק אותו אוטומטית
אל `app/src/main/assets/www`. אחר כך בונים את ה־APK שוב, ומעלים את `versionCode` בקובץ `app/build.gradle`.

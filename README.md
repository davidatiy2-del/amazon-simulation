# אמזוניה: הישרדות בג׳ונגל

משחק הישרדות תלת־ממדי בג׳ונגל של דרום אמריקה. במאגר יש שתי גרסאות:

| תיקייה | מה יש בה |
|---|---|
| [`godot/`](godot) | **הגרסה החדשה**, במנוע Godot 4.3, לאנדרואיד. שלב 1: הג׳ונגל והנהר, הצייד עם חנית ואנימציות, חיות עם התנהגות, יום ולילה, שליטה במגע ושמירה. שלב 2: הים, הסירות, ציד לווייתנים מספינה, והעולם החדש מעבר לים. |
| [`web/`](web) | **הגרסה המקורית**: דף HTML אחד עם Three.js, וגם אפליקציית אנדרואיד שעוטפת אותו. יש בה כל המערכות: שבטים, כפר ועיר, תושבים ותפקידים, פשיטות, כרייה, שמירה בענן וקודי העברה. |

המערכות של הגרסה המקורית עוברות ל־Godot אחת אחת.

---

## הגרסה החדשה (`godot/`)

**לפתוח:** מתקינים [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/), בוחרים Import ופותחים את `godot/project.godot`. בפתיחה הראשונה Godot מייבא את כל הנכסים, וזה לוקח כמה דקות.

**העולם** (1 על 3 ק״מ, מצפון לדרום):

- **הג׳ונגל**: גבעות, נהר שזורם אל הים, אגם ונחל, והרים במערב, במזרח ובצפון. על החוף הדרומי יש נמל עם מזח, סירה וספינת ציד.
- **הים**: מדף רדוד ליד החופים ומים עמוקים באמצע. יש שני איים, ועל הגדול מהם שוכבת ספינה טרופה. בים חיים לווייתנים, כרישים, דולפינים ושחפים.
- **העולם החדש**: מישורי עשב ופרחים לאורך החוף, גבעות עם יערות אורנים, אגם, והרים בקצוות. חיים בו זברות, סוסי בר, איילים וזאבים אפורים. גם בו יש נמל עם סירה.

**בים:**

- **סירה:** ליד המזח עולים בכפתור "לעלות". המקל מכוון את הסירה, "חתירה" מאיצה אותה (על חשבון האנרגיה), וליד החוף או ליד המזח יורדים בכפתור "לרדת".
- **ספינת הציד:** כפתור "צלצל" זורק צלצל אל הלווייתן הקרוב, אבל רק כשהוא קרוב לפני המים. "מפרש" משיט את הספינה מהר יותר. לווייתן פגוע בורח וגורר את הספינה בחבל, ולפעמים מסתובב ונוגח בה. כשגוף הספינה נשבר היא טובעת, וספינה חדשה מחכה בנמל אחרי דקה וחצי.
- **לווייתן מת** צף על הגב. מתקרבים אליו וב"לבתר" מקבלים בשר לימים ושלוש חביות שמן.
- **שחייה בים העמוק** מכלה את האנרגיה, ובלי אנרגיה טובעים. כרישים תוקפים רק מי שבמים.
- **מים לשתייה** יש רק בנהרות ובאגמים, לא בים.
- **ניווט:** בראש המסך מוצגים כיוון הנמל ומרחקו.

**המבנה:**

| קובץ | תפקיד |
|---|---|
| `scenes/main.tscn` + `scripts/game.gd` | המשחק: טעינת העולם ברקע, תפריט, שמירה כל 20 שניות, איכות גרפיקה |
| `scripts/player.gd` | הצייד: הליכה, ריצה, שחייה, התחמקות, מכת חנית, אכילה ושתייה, מזון, מים ואנרגיה, עלייה לסירה, זריקת צלצל |
| `scripts/boat.gd` | הסירה וספינת הציד: היגוי, גלים, מים רדודים, מזחים, גוף שנשבר וספינה חדשה בנמל |
| `scripts/sea/` | חיות הים (לווייתנים, כרישים, דולפינים, שחפים), הצלצלים והחבל, ודולפין שבנוי מקוד |
| `scripts/animal.gd`, `scripts/animals.gd` | חיות היבשה: בג׳ונגל צבי, שועל, זאב רעמה וצפרדע, ובעולם החדש זברה, סוס בר, אייל וזאב אפור. הן רועות, בורחות וצדות, ומשאירות גופה עם בשר. כל חיה חיה בארץ שלה, מופיעה סביב הצייד ונעלמת כשהוא מתרחק |
| `scripts/camera_rig.gd` | מצלמה מאחורי הכתף שלא נכנסת לקרקע |
| `scripts/ui/` | שליטה במגע (מקל, גרירה, כפתורים, כל אצבע לחוד) ותצוגה (מדדים, שעון, הודעות, מסכים) |
| `scripts/world/` | צורת העולם (חופים, נהר, אגמים, איים, העולם החדש), גובה הקרקע והמזחים, הגלים (אותם גלים כמו בצבע המים), יום ולילה |
| `shaders/` | הקרקע והמים: נהר עכור, חוף טורקיז, ים עמוק, גלים וקצף |
| `world/` | העולם הבנוי: `world.scn` (קרקע, מים, מזחים וכ־480 אלף צמחים), `height.bin`, `trunks.bin`, `places.json` (הנמלים, נקודת ההתחלה) |
| `tools/` | כלים: בניית העולם, משחק אוטומטי עם צילומי מסך, צפייה בעולם ובדגמים |

**לבנות את העולם מחדש** (אחרי שינוי ב־`world_shape.gd` או ב־`tools/worldgen.gd`):

```sh
godot --path godot --rendering-driver vulkan --script tools/worldgen.gd
```

צריך לבנות עם רינדור אמיתי (Vulkan). בלי רינדור (`--headless`) מיקומי הצמחים לא נשמרים.

**לבדוק בלי טלפון:** המשחק משחק לבד ושומר צילומי מסך לתיקייה:

```sh
godot --path godot -- auto /tmp/shots          # הליכה, חיות, תקיפה, לילה, השהיה
godot --path godot -- auto /tmp/shots look     # הצייד מלפנים בשש שעות של היממה
godot --path godot -- auto /tmp/shots sea      # המזח, הספינה, ציד לווייתן, חתירה, העולם החדש, כריש
godot --path godot -- auto /tmp/shots ram      # לווייתן נוגח בספינה עד שהיא טובעת
godot --path godot -- auto /tmp/shots save     # שמירה כשהצייד בסירה באמצע הים, וחזרה אליה
```

**לבנות APK:** Project → Export → Android (צריך את תבניות הייצוא של Godot 4.3 ואת Android SDK). מפתח החתימה **לא נמצא במאגר**:
- שמים את `amazonia.jks` בתיקייה `godot/keystore/`.
- את השם והסיסמה מזינים בחלון הייצוא. Godot שומר אותם רק אצלך, ב־`.godot/export_credentials.cfg`.

## הגרסה המקורית (`web/`)

```sh
cd web
python3 build.py     # בונה את amazonia.html, את dist/www ואת העותק לאפליקציה
./check.sh           # בנייה + בדיקת קוד
```

- **הקוד:** חלקים ב־`src/js/` (לפי סדר המספרים), עיצוב ב־`src/css/`, והדף ב־`src/index.html`.
- **בדיקות:** ב־`tests/`, עם Playwright.
- **אפליקציית האנדרואיד:** ב־`android/` (Gradle ו־WebView). `keystore.properties` ומפתח החתימה לא נמצאים במאגר. ההוראות ב־`android/README-he.md`.

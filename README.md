# אמזוניה: הישרדות בג׳ונגל

משחק הישרדות תלת־ממדי בג׳ונגל של דרום אמריקה. במאגר יש שתי גרסאות:

| תיקייה | מה יש בה |
|---|---|
| [`godot/`](godot) | **הגרסה החדשה**, במנוע Godot 4.3, לאנדרואיד. שלב 1: הג׳ונגל והנהר, הצייד עם חנית ואנימציות, חיות עם התנהגות, יום ולילה, שליטה במגע ושמירה. |
| [`web/`](web) | **הגרסה המקורית**: דף HTML אחד עם Three.js, וגם אפליקציית אנדרואיד שעוטפת אותו. יש בה כל המערכות: שבטים, כפר ועיר, תושבים ותפקידים, פשיטות, כרייה, שמירה בענן וקודי העברה. |

המערכות של הגרסה המקורית עוברות ל־Godot אחת אחת.

---

## הגרסה החדשה (`godot/`)

**לפתוח:** מתקינים [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/), בוחרים Import ופותחים את `godot/project.godot`. בפתיחה הראשונה Godot מייבא את כל הנכסים, וזה לוקח כמה דקות.

**המבנה:**

| קובץ | תפקיד |
|---|---|
| `scenes/main.tscn` + `scripts/game.gd` | המשחק: טעינת העולם ברקע, תפריט, שמירה כל 20 שניות, איכות גרפיקה |
| `scripts/player.gd` | הצייד: הליכה, ריצה, שחייה, התחמקות, מכת חנית, אכילה ושתייה, מזון, מים ואנרגיה |
| `scripts/animal.gd`, `scripts/animals.gd` | החיות (צבי, שועל, זאב רעמה, צפרדע): רעייה, בריחה, ציד, גופה עם בשר. מופיעות סביב הצייד ונעלמות כשהוא מתרחק |
| `scripts/camera_rig.gd` | מצלמה מאחורי הכתף שלא נכנסת לקרקע |
| `scripts/ui/` | שליטה במגע (מקל, גרירה, כפתורים, כל אצבע לחוד) ותצוגה (מדדים, שעון, הודעות, מסכים) |
| `scripts/world/` | צורת העולם (גבעות, נהר, נחל, אגם), גובה הקרקע מתוך `height.bin`, יום ולילה |
| `shaders/` | הקרקע והמים |
| `world/` | העולם הבנוי: `world.scn` (קרקע, מים, כ־280 אלף עצים, שיחים, שרכים, פרחים ועשב), `height.bin`, `trunks.bin` |
| `tools/` | כלים: בניית העולם, משחק אוטומטי עם צילומי מסך, צפייה בעולם ובדגמים |

**לבנות את העולם מחדש** (אחרי שינוי ב־`world_shape.gd` או ב־`tools/worldgen.gd`):

```sh
godot --path godot --rendering-driver vulkan --script tools/worldgen.gd
```

צריך לבנות עם רינדור אמיתי (Vulkan). בלי רינדור (`--headless`) מיקומי הצמחים לא נשמרים.

**לבדוק בלי טלפון:** המשחק משחק לבד ושומר צילומי מסך לתיקייה:

```sh
godot --path godot -- auto /tmp/shots          # הליכה, חיות, תקיפה, לילה, השהיה
godot --path godot -- auto /tmp/shots look     # הצייד מלפנים בשש שעות של היממה
```

**לבנות APK:** Project → Export → Android (צריך את תבניות הייצוא של Godot 4.3 ואת Android SDK). מפתח החתימה **לא נמצא במאגר**:
- שמים את `amazonia.jks` בתיקייה `godot/keystore/`.
- את השם והסיסמה מזינים בחלון הייצוא. Godot שומר אותם רק אצלך, ב־`.godot/export_credentials.cfg`.

## הגרסה המקורית (`web/`)

```sh
cd web
python3 build.py     # בונה את amazonia.html, את dist/www ואת העותק לאפליקציה
./check.sh           # בנייה + בדיקת קוד
```

- **הקוד:** חלקים ב־`src/js/` (לפי סדר המספרים), עיצוב ב־`src/css/`, והדף ב־`src/index.html`.
- **בדיקות:** ב־`tests/`, עם Playwright.
- **אפליקציית האנדרואיד:** ב־`android/` (Gradle ו־WebView). `keystore.properties` ומפתח החתימה לא נמצאים במאגר. ההוראות ב־`android/README-he.md`.
